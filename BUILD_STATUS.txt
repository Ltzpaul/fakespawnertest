Build status: SOURCE PROJECT ONLY — no compiled JAR is included.

The build was not executed in the file-generation environment because Gradle was not installed and outbound access to services.gradle.org was unavailable. Java 21 is present, but that alone is not enough to compile a Fabric mod without Gradle/Minecraft/Fabric dependency artifacts.

To build on a Windows computer with internet access and JDK 21 installed:
  1. Extract this ZIP.
  2. Open Command Prompt or PowerShell in the extracted folder.
  3. Run: gradlew.bat build
  4. Find the remapped JAR in: build\libs\fake-spawner-1.0.0.jar

The included gradlew/gradlew.bat scripts bootstrap the Gradle 8.14.2 distribution; gradle-wrapper.properties also pins the same Gradle version. They are lightweight bootstrap launchers, not the standard Gradle wrapper JAR distribution.
